# 商业视频全流程策划工作流 · 工作台

一个覆盖**全商业视频类型**（广告片 / 企业宣传片 / 微电影 / 产品宣传片 / 短视频）的
策划工作系统。把参考文档《商业视频全流程策划工作流与AI提示词体系》落成一个**可操作的工作台**：

- **8 大标准环节**分模块实现，每步产出即下一步输入，闭环不发散
- 每个环节自动渲染**贴合上下文的 AI 提示词**（含视频类型差异化参数），复制即用
- 结构化沉淀每个环节产出，最终**一键导出 15 页标准可提报 PPTX 创意方案**

---

## 一、快速开始

```bash
# 1. 安装依赖（任选一个 Python 解释器，需同时具备 streamlit 与 python-pptx）
pip install -r requirements.txt

# 2. 启动工作台
streamlit run app.py
# 或： python3 -m streamlit run app.py

# 3. 浏览器打开提示的本地地址（默认 http://localhost:8501）
```

> 环境说明：本机若 `streamlit` 与 `python-pptx` 分属不同 Python 版本，请确保**运行 app 的解释器同时装有两者**。
> 已验证：`python3.12`（系统，`streamlit` 命令所在）已装 `python-pptx`；`python3.11` 已装 `streamlit`。

## 二、工作台结构（侧边栏导航 9 项）

| 导航 | 环节 | 产出 | 自动提示词 |
|---|---|---|---|
| ⚙️ 项目设置 | 全局上下文 | 影片类型/时长/画幅/渠道/受众/主色 | — |
| 📋 需求提炼 | 环节1 | 《需求简报 BRD》 | ✅ |
| 💡 创意策划 | 环节2 | 3 套差异化创意方向（含选定方向） | ✅ |
| 📝 创意脚本 | 环节3 | 文学脚本 + 参考视频清单 | ✅ |
| 🎬 文字分镜 | 环节4 | 八列分镜表（拍摄蓝图） | ✅ |
| 🖼️ 分镜图 | 环节5 | 逐镜故事板提示词 + 上传成图 + 一致性锁定 | ✅ |
| 🎞️ 动态分镜 | 环节6 | Animatic 剪辑规范（节奏校验） | ✅ |
| 🎨 提报资料 | 环节7 | 影调/风格/美术/置景/演员/服化道 | ✅ |
| 📊 PPT 整合 | 环节8 | 15 页可提报方案导出 | — |

**链式串联**：环节2 的提示词读取环节1 的 BRD；环节3 读取选定方向；环节4 读取脚本；
环节5 按环节4 镜头逐个生成分镜图提示词；环节6/7 读取上游脚本与分镜…… 全程自动带参。

## 三、典型使用流程

1. **项目设置**：填好影片类型 / 时长 / 画幅 / 渠道 / 受众。影片类型决定后续差异化参数。
2. **需求提炼**：粘贴客户原话 → 复制提示词给大模型 → 把 BRD 七项回填。
3. **创意策划**：复制提示词生成 3 方向 → 回填并**选定提报方向**。
4. **创意脚本 → 文字分镜 → 分镜图 → 动态分镜**：线性推进，每步复制提示词、回填产出；
   分镜图环节可上传成图（自动保存到 `uploads/`）。
5. **提报资料**：并行整理影调 Moodboard、风格参考、角色服化道、美术置景与道具。
6. **PPT 整合**：点「🚀 生成并导出 PPTX」，自动套用全部结构化产出，下载 15 页方案。

随时可用侧边栏「💾 项目备份 / 导入」导出/导入 JSON，或「🗑 清空重置」。

```

├── app.py                  # Streamlit 主应用（整合所有模块）

└── output/                 # 导出的 PPTX
```

## 五、自定义与扩展

- **改主色 / 封面**：项目设置里调「提报 PPT 主色」；`core/ppt_builder.py` 内 `_cover/_p15_end` 控制封面与结尾。
- **加视频类型**：在 `core/config.py` 的 `VIDEO_TYPES` 增加类型与差异化参数，提示词自动带上。
- **调页面结构**：`core/ppt_builder.py` 中每个 `_pN_*` 函数对应一页，按需增删。
- **接大模型 API**：当前为「提示词复制」模式（最稳、无需密钥）。如需自动生成，可在各
  `modules/stageX.py` 的 `build_prompt()` 后接调用，把返回回填到对应字段。

## 七、打不开 Streamlit 服务？用独立网页版

若运行环境无法访问 Streamlit 的端口（防火墙/无端口转发），改用 **`standalone/` 纯前端版**：
直接用浏览器打开 `standalone/workbench.html` 即可，**无需服务器、无需联网**（PPT 库已内置本地）。
详见 `standalone/README.md`。功能与 Streamlit 版完全一致。
